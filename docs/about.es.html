Acerca de esta aplicación

Un simulador de cubo 3x3 que funciona completamente en tu navegador. Sin instalación, sin pasar por ninguna tienda de aplicaciones: basta con abrir esta página para empezar a jugar de inmediato.

Ofrece soporte para todos los niveles, desde un tutorial paso a paso (método LBL) para quienes no saben cómo resolver el cubo, hasta herramientas de análisis para quienes buscan mejorar su tiempo.

Qué puedes hacer con esta aplicación

  • Controles intuitivos: basta con deslizar el dedo
  • Aprende los fundamentos paso a paso con el tutorial guiado (disponible en 9 idiomas)
  • Registra cualquier secuencia de movimientos como un "comando" y reprodúcela con un doble toque
  • Resolución automática mediante un solver externo
  • Registro de tiempos y reproducción/retroceso del historial de movimientos
  • Vista de diagrama desplegado (net) y control libre del ángulo de cámara

Consulta el README para más detalles.

Sobre la seguridad de esta aplicación

  • Priorizamos tu disfrute: esta aplicación no muestra ningún anuncio, y no tenemos planes de introducir publicidad en el futuro
  • Esta aplicación se comunica con un servicio externo (solver) que calcula las soluciones del cubo, pero solo se envía una cadena de texto que representa el estado del cubo. Nunca se envía tu nombre, información del dispositivo, datos de uso ni ninguna otra información que te identifique personalmente
  • El análisis de acceso se realiza sin cookies ni ninguna información que te identifique personalmente; solo se recopilan estadísticas anónimas y agregadas, como las vistas de página
  • La información almacenada únicamente en tu navegador (localStorage) se limita a lo siguiente. Toda ella permanece en tu propio dispositivo y nunca se envía a ningún sitio:
    • Ajustes como velocidad, idioma, visualización de ejes y comandos configurados
    • Puntuaciones más altas (tiempos registrados)
    • Progreso del tutorial
